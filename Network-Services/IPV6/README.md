# IPv6 Labs

Hands-on Cisco Packet Tracer labs focused on IPv6 addressing, configuration, and connectivity.

## Topics Practiced

- IPv6 addressing
- Global unicast addresses
- Link-local addresses
- IPv6 interface configuration
- IPv6 routing
- Neighbor discovery
- IPv6 connectivity testing
- IPv6 troubleshooting

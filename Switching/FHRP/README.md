# FHRP Labs

Hands-on Cisco Packet Tracer labs focused on First Hop Redundancy Protocol concepts.

## Topics Practiced

- FHRP configuration
- Default gateway redundancy
- Gateway failover
- High availability
- Redundant router configuration
- FHRP troubleshooting
- Connectivity verification

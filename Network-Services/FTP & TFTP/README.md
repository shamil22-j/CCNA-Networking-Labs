# TFTP Labs

Hands-on Cisco Packet Tracer labs focused on Trivial File Transfer Protocol (TFTP) for network device configuration and file management.

## Topics Practiced

- TFTP server configuration
- Backup of device configurations
- Restoring configurations
- File transfer between network devices and TFTP server
- TFTP troubleshooting
- Connectivity verification

## Verification Commands

show running-config
show startup-config
copy running-config tftp:
copy tftp: running-config
ping

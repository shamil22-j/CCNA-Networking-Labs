# EIGRP Labs

Hands-on Cisco Packet Tracer labs focused on Enhanced Interior Gateway Routing Protocol (EIGRP).

## Topics Practiced

- EIGRP configuration
- Neighbor adjacency
- Network advertisement
- Routing table verification
- EIGRP troubleshooting
- Connectivity testing

## Verification Commands

show ip eigrp neighbors
show ip route eigrp
show ip protocols
show ip eigrp topology
show running-config
ping
traceroute

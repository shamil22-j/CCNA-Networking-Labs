# VLAN Labs

Hands-on Cisco Packet Tracer labs focused on VLAN configuration and Layer 2 network segmentation.

## Topics Practiced

- VLAN creation and configuration
- Access ports
- Trunk ports
- VLAN assignment
- Inter-VLAN communication
- Router-on-a-Stick
- VLAN troubleshooting
- Connectivity verification

## Verification Commands

show vlan brief
show interfaces trunk
show running-config
show ip interface brief
ping

# CCNA Networking Labs

A collection of hands-on Cisco networking labs and troubleshooting scenarios
completed using Cisco Packet Tracer while developing practical networking skills.

## 🛠️ Technologies & Tools

- Cisco Packet Tracer
- Cisco IOS CLI
- IPv4 / IPv6
- TCP/IP
- Network troubleshooting

## 📚 Topics Covered

### Routing
- Static Routing
- RIP
- OSPF
- EIGRP

### Switching
- VLANs
- Trunking
- Inter-VLAN Routing
- EtherChannel
- FHRP

### Network Services
- DHCP
- DHCP Relay
- DNS
- NTP
- TFTP

### Network Addressing
- NAT
- IPv6
- IP Addressing

### Network Security
- ACL
- AAA
- Device Access Security

### Remote Access
- Telnet

### Troubleshooting
- OSPF Troubleshooting
- RIP Troubleshooting
- EIGRP Troubleshooting
- Connectivity Troubleshooting

## 🔍 Practical Skills

- Cisco IOS device configuration
- IP addressing and subnetting
- Routing protocol configuration
- VLAN and switching configuration
- Network service configuration
- Access control and device security
- Network connectivity testing
- Troubleshooting using Cisco IOS commands
- Configuration verification and fault isolation

# DNS Labs

Hands-on Cisco Packet Tracer labs focused on Domain Name System (DNS) configuration and name resolution.

## Topics Practiced

- DNS server configuration
- DNS records
- Hostname-to-IP resolution
- Client DNS configuration
- DNS troubleshooting
- Testing name resolution

## Verification

- Configure DNS server
- Configure clients with DNS server address
- Test hostname resolution
- Verify connectivity using `ping`
